# Arrays Home Assignment

This repository contains my Java homework assignments about arrays.

## Tasks

### Task 1 – Replace
- Find negative numbers in an array.
- Replace all negative numbers with `0`.
- Count how many numbers were replaced.

### Task 2 – Distinct
- Find distinct numbers in an array.
- Print each number only once.

### Task 3 – Remove
- Remove an element from an array using its index.
- Shift the remaining elements to the left.
- Print the updated array.

### Task 4 – Find Duplicate Numbers
- Find numbers that appear more than once.
- Print each duplicate only once.
- Display a message if there are no duplicates.

## Technologies Used
- Java

- For Loops
- Nested Loops
- If-Else Statements
- Boolean Variables
